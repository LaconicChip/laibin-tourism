# 来宾旅行笔记

广西来宾的文旅站点，按「一个人写的旅行笔记」组织：先给数字（门票、开放时间、车程），再给判断，最后才是形容词。

## 这一版的原则

**有几张真图，就写几个地方。**

上一版 24 处里只有 7 处拿到实拍。这一版把剩下 17 处逐个找了一遍：能拿到图的补上，拿不到的**直接从清单里删掉**。最终保留 13 处，每一处都有实拍，每一张图都标了出处。

删掉的 11 处：莲花山、圣堂湖、银杉森林公园、瑶族博物馆、武宣文庙、麒麟山人遗址、蓬莱洲（时光岛）、四月八岭、运江古镇、瑶天下民宿、政和步行街。不是它们不值得去，是我找不到能合法使用的照片——宁可清单短，不拿示意图凑数。

## 设计

- 三色：纸白 `#FBF9F4` / 近黑 `#1A1B1C` / 朱砂 `#B03A2B`
- 字体：标题 Noto Serif SC（本机 `NotoSerifSC-VF.ttf` 用 fontTools 裁成 1296 字子集，470KB）；正文系统中文黑体栈，零外部请求
- 版式：直角、1px 细线、非对称栅格；清单行按 `名称 | 一句话 | 时长/开放时间 | 票价/备注` 排数据
- 图片：首屏 3.2:1、特写 3:2、缩略图 96×66；统一降饱和与暖调，抵消官方海报的过饱和

- 地图是同心块示意图，只表达方位关系，不表达面积与边界。
